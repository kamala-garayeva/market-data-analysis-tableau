# Market Data Analysis — Tableau Dashboard 📊

## 🔗 Live Dashboard
👉 [View on Tableau Public](https://public.tableau.com/app/profile/kamala.garayeva/viz/Book1_17789303984890/Dashboard1)

## Objective
Build an interactive, self-service dashboard that transforms raw market data into
clear visual insights — enabling stakeholders to explore trends, compare segments,
and make data-driven decisions without needing technical skills.

## What the Dashboard Shows
- Market performance trends over time
- Category/segment breakdowns and comparisons
- Key metrics highlighted for quick executive-level reading
- Interactive filters allowing users to slice data by relevant dimensions

## Process
1. **Data preparation** — cleaned and structured raw market data for Tableau ingestion
2. **Dashboard design** — chose chart types best suited to each insight (bar, line, KPI tiles)
3. **Interactivity** — added filters and highlight actions for self-service exploration
4. **Storytelling** — arranged layout to guide the viewer from summary to detail

## Why This Matters
Interactive dashboards reduce dependency on analysts for routine data questions.
This project demonstrates the ability to design for non-technical audiences —
a critical skill in any data analyst role.
